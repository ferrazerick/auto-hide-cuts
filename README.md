Criado com o objetivo de facilitar meu dia a dia na empresa em que trabalho.
Usando um serviço web onde, quando eu preciso alterar alguns itens, preciso selecionar manual 4  categorias
para só então pode preencher o código referente ao item. Isso toma muito tempo quando é necessário fazer com vários itens.
Então, criei este programa pra que eu possa enviar somente a lista de códigos e o sessionId, para ele fazer a requisição em loop,
visto que em todos os produtos eu faço exatamente a mesma alteração.
O servidor oficial não suporta o envio de códigos em grupo, então eu faço isso por fora, enviando requisições em loop, até findar a lista.
